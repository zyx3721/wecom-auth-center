## 📋 版本概述

本版本围绕「版本可观测」与「服务器运维补充」两项增强：服务端新增 `-v` / `--version` 命令行参数，发布流水线在编译期注入版本号、commit 与构建时间，升级部署后可直接确认运行版本；同时新增服务器启停管理脚本，完善二进制部署场景下的日常运维。

HTTP 接口与配置文件格式无任何变更，已接入的业务系统无需改造，升级仅需替换二进制或拉取新镜像。

---

## ✨ 新增特性

- **`-v` / `--version` 版本查询参数** — 直接输出版本号、commit、构建时间与 Go 版本；版本检查在配置加载之前执行，未就绪 `config.yaml` 也可查询
- **构建信息注入** — CI 六平台二进制编译与 Docker 镜像构建统一通过 `-ldflags -X` 注入版本号（tag 名）、commit 短 hash 与 UTC 构建时间；源码直接编译默认显示 `dev`
- **服务器启停管理脚本** — 新增 `scripts/run.sh`，支持 `start` / `stop` / `restart`，含 PID 存活校验、陈旧 PID 清理与超时强制停止兜底

## 🔄 API 变更

HTTP 接口无变更。命令行参数新增：

| 参数 | 说明 |
| --- | --- |
| `-v` / `--version` | 显示版本信息并退出（版本号由 CI 构建时注入，源码编译显示 `dev`） |

注意：v1.0.0 及更早的二进制不含该参数，需升级至本版本后使用。

---

## 🔄 升级说明

1. Docker：`docker pull` 新镜像后按原命令重新创建容器；二进制：替换可执行文件后重启服务
2. 升级后执行 `./wecom-auth-center -v`（Docker 用 `docker exec <容器名> /app/wecom-auth-center -v`）确认版本已更新
3. `config.yaml` 无格式变更，无需迁移；已接入业务系统无需任何改造
