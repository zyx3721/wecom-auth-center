# wecom-auth-center v1.2.3 版本更新日志

**发布日期**: 2026-09-24  
**提交数量**: 10 次提交  
**版本类型**: 向下兼容功能版本（含新特性与重构）

---

## 📋 版本概述

本版本围绕成员档案与监控页体验完成一轮增强：verify 接口在开启 `fetch_profile` 后可返回部门、邮箱与员工编码档案字段；监控页最近登录流水支持行点击查看成员档案弹窗，详情键值行悬浮可查看完整内容；成员信息统一精简为姓名/员工编码/部门层级路径并补充告警日志。同时监控页 favicon 与品牌 logo 从内嵌 data URI 外置为 `web/static/` 下的独立 SVG 文件，随镜像构建一并分发，页面改为直接引用。另完成注释与文档中的内部风格表述清理，并移除全部单元测试文件。

---

## ✨ 新增特性

- **verify 接口支持档案字段** — 开启 `fetch_profile` 后，`/api/verify` 响应在 `userid`、`name` 之外返回部门（含完整层级路径）、邮箱与员工编码等成员档案字段；未开启时响应形状恒定（零值），业务系统可统一解析
- **监控页最近登录档案弹窗** — 最近登录流水支持行点击，弹窗查看该成员完整档案信息
- **监控详情悬浮查看完整内容** — 详情弹窗中的键值行悬浮时以内置样式展示完整内容，长内容不再截断
- **监控页图标外置** — 站点图标与品牌 logo 外置为 `server/web/static/favicon.svg` 与 `logo.svg`，经静态目录直接服务（`/favicon.svg`、`/logo.svg`），随 Docker 镜像构建一并分发

## 🔄 API 变更

- `/api/verify`：开启 `fetch_profile` 后响应新增档案字段（部门层级路径、邮箱、员工编码），向下兼容
- `/favicon.svg`、`/logo.svg`：监控页图标改由静态目录提供，无 Token 保护（不含敏感信息）；无新增受保护接口
- 监控页 HTML 中 favicon 由内嵌 data URI 改为外部文件引用，接口行为无任何变更

## 🔄 升级说明

1. 替换二进制或镜像并重启即生效，配置无需任何变更；
2. Docker 镜像已内置监控页图标；**Release 二进制部署需保留部署目录下的 `web/static/`**（与企微域名校验文件的既有要求一致），否则监控页图标将 404；
3. 已接入业务系统如需获取成员档案，在配置中开启 `fetch_profile` 并重新对接 verify 响应字段即可；
4. 升级后执行 `./wecom-auth-center -v` 确认版本已更新。
