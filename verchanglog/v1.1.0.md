## 📋 版本概述

本版本完成阶段三加固规划的两项核心能力：**Redis 存储驱动**与**安全审计日志**。Redis 支持多实例部署时共享进行中的登录流程（`SET EX` + `GETDEL`，与内存版「取出即删」语义一致）；审计日志以独立 JSON 行文件完整留痕登录链路的成功与拒绝事件。同时优化服务端帮助信息的参数展示格式。

HTTP 接口无任何变更，新增配置段均有向下兼容的默认值（内存存储、审计关闭），已接入的业务系统无需改造。

---

## ✨ 新增特性

- **Redis 存储驱动** — `store.driver: redis` 切换，state/ticket 以 `SET EX` 写入、`GETDEL` 原子取出即删（要求 Redis 6.2+），多实例部署共享；启动时 Ping 校验连通，失败拒绝启动
- **安全审计日志** — `audit.enabled` 开启后，登录发起（`login_start`）、ticket 签发（`ticket_issue`）、兑换成功（`verify_ok`）及全部拒绝事件（`state_reject` / `verify_app_reject` / `verify_sign_reject` / `verify_ts_reject` / `ticket_reject` / `ticket_mismatch`）独立落盘为 JSON 行文件，含 app/userid/remote 字段；文件打开失败拒绝启动，避免安全事件失录
- **帮助信息优化** — `-h`/`--help` 输出中 `-v, -version` 合并一行展示，描述统一换行缩进对齐

## 🔄 API 变更

HTTP 接口无变更。配置新增（均含默认值，存量配置无需修改）：

| 配置段 | 说明 |
| --- | --- |
| `store.driver` | `memory`（默认）/ `redis`，多实例部署选 redis |
| `store.redis.*` | Redis 地址、密码与逻辑库 |
| `audit.enabled` / `audit.path` | 审计开关与文件路径（默认关闭 / `audit.log`） |

命令行 `-h`/`--help` 输出格式调整：`-v, -version` 合并一行展示。

## 🔄 升级说明

1. 配置文件无需迁移：新增 `store`、`audit` 段均有向下兼容默认值（内存存储、审计关闭）
2. 多实例部署：将 `store.driver` 改为 `redis` 并配置 `store.redis.addr`（要求 Redis 6.2+）
3. Docker 启用审计：审计文件须落在挂载的可写目录（如 `-v /opt/wecom-auth-center/audit:/app/audit` 并设 `audit.path`），否则服务拒绝启动
4. 升级后执行 `./wecom-auth-center -v` 确认版本已更新
