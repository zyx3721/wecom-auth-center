## 📋 版本概述

本版本放开业务系统域名的协议限制并修复启停脚本：`apps.*.domain` 支持 `http://`（面向内网系统场景），启动时对 HTTP 域名输出 Warn 明文传输提示；认证中心自身的 `server.external_url` 因属企业微信回调域仍强制 HTTPS，不受影响。同时启停脚本改为显式指定配置文件路径，不再依赖默认相对路径。

HTTP 接口无变更，配置向下兼容（存量 HTTPS 域名配置不受任何影响），已接入业务系统无需改造。

---

## ✨ 新增特性

- **业务系统域名支持 HTTP** — `apps.<app>.domain` 校验放宽为 `http(s)://` 开头，内网系统可直接使用 HTTP 域名接入
- **明文传输告警** — 启动时对使用 HTTP 的业务系统域名逐个输出 Warn 日志（`业务系统域名使用 HTTP，ticket 将明文传输，请确认内网可信`，含 app 与 domain 字段），生产环境建议仍使用 HTTPS

---

## 🐛 Bug 修复

- **启停脚本显式指定配置文件路径** — `scripts/run.sh` 启动与重启时显式传 `-config` 参数（`$BASE_DIR/config.yaml`），不再依赖进程工作目录下的默认路径

## 🔄 API 变更

HTTP 接口无变更。配置校验调整：

| 配置项 | 调整前 | 调整后 |
| --- | --- | --- |
| `apps.<app>.domain` | 仅允许 `https://` | 允许 `https://` 与 `http://`（HTTP 启动时 Warn 提示） |
| `server.external_url` | 强制 `https://` | 不变（企业微信回调域硬性要求） |

## 🔄 升级说明

1. 配置无需迁移：存量 HTTPS 域名行为不变，内网 HTTP 场景直接修改 `apps.<app>.domain` 后重启即可
2. 升级后执行 `./wecom-auth-center -v` 确认版本已更新
3. 服务器使用启停脚本部署的，本版本脚本已显式指定配置路径，替换脚本后重启生效
