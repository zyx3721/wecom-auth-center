## 📋 版本概述

本版本完成阶段五规划：内置 **KMS 风格轻量监控页**。开启 `status` 配置后，访问 `/status?token=令牌` 即可查看近 7 天登录趋势、今日登录/签发/兑换/拒绝统计、版本与构建信息、存储驱动与 Redis 在线状态，30 秒自动刷新。页面为全视口仪表盘（自绘 SVG 平滑曲线，零外部图表库），支持图表悬停提示、统计卡点击明细弹窗等完整交互；统计数据按日分桶落盘，重启历史不丢。

既有业务接口（/login、/callback、/api/verify、/healthz）行为无任何变更，`status` 默认关闭，配置向下兼容，已接入业务系统无需改造。

---

## ✨ 新增特性

- **内置监控页 `/status`** — 全视口 KMS 风格仪表盘：4 张统计卡（近 7 天登录发起/登录成功、今日登录发起/今日兑换成功）、近 7 天趋势图（页面内自绘 SVG 平滑曲线 + 面积渐变，零第三方依赖、离线可用）、监控节点卡（存储驱动与 Redis 在线状态、企微模式、今日四项指标）、服务信息表（版本/构建/平台/主机/运行时长/监听地址/检测时间）
- **数据接口 `/api/status`** — 实时快照输出：每次请求从内存计数器现算，无缓存滞后；含统计卡、今日拒绝事件明细、7 天逐日序列、运行信息与存储健康
- **完整交互** — 图表悬停提示框 + 十字辅助线 + 数据点放大；统计卡与指标格点击弹出明细弹窗（按日明细 / 今日事件双页签）；数字滚动动画；ESC / 遮罩 / 按钮三种方式关闭弹窗
- **Token 访问保护** — 页面与接口均要求 `?token=` 令牌（恒定时间比较），缺/错令牌 403、未启用 404；令牌可由浏览器 localStorage 记忆
- **统计数据持久化** — 与审计事件同名同点位采集 9 类事件，按日分桶保留 7 天，每 60 秒原子落盘至 `status.data_path`，启动自动恢复，重启历史不丢
- **存储健康检查** — `store` 包新增 `HealthChecker` 接口：Redis 实现 2 秒 Ping 探测、内存实现恒为健康，监控页实时展示在线状态

## 🔄 API 变更

业务接口无变更。新增监控相关接口与配置：

| 类型 | 内容 |
| --- | --- |
| GET `/status?token=` | 监控页（`status.enabled` 开启后可用，未启用 404） |
| GET `/api/status?token=` | 监控数据 JSON（Token 保护，缺/错令牌 403） |
| 配置 `status.*` | `enabled`（默认 false）/ `token`（启用必填）/ `data_path`（默认 `status-metrics.json`） |

## 🔄 升级说明

1. 配置无需迁移：`status` 默认关闭，存量配置零影响；开启时设 `status.enabled: true` 并配置 `token`（建议 `openssl rand -hex 16` 生成）
2. Docker 部署启用监控时，`data_path` 须落在挂载的可写目录（如 `-v /opt/wecom-auth-center/data:/app/data` 并设 `data_path: "/app/data/status-metrics.json"`）
3. 升级后执行 `./wecom-auth-center -v` 确认版本已更新
