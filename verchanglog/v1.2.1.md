## 📋 版本概述

本版本为监控页的功能增强与体验修复：新增**「最近登录」流水面板**——逐条展示成功扫码登录的时间、企微账号（userid）、姓名、来源应用与登录发起 IP，最多保留 50 条并随统计文件持久化；同步优化监控页布局（趋势图高度减半、流水卡片等宽承接、流水五列等宽居中、空状态居中），并修复趋势曲线在「零值段紧邻峰值段」时向下越过 0 基线的过冲问题。

HTTP 业务接口无变更，配置无需迁移，已接入业务系统无需改造。

---

## ✨ 新增特性

- **最近登录流水面板** — 监控页左列趋势图下方新增「最近登录」卡片，逐条展示登录时间（完整年份格式）、企微账号 userid、姓名、来源应用与登录发起 IP；最多保留 50 条，随统计文件原子落盘、重启不丢
- **登录发起 IP 采集** — `/login` 时将浏览器来源 IP（反代后取 `X-Real-IP`）随 state 传递，扫码成功后在流水中关联展示
- **五列等宽流水样式** — 时间/企微账号/姓名/应用/IP 五列 `1fr` 等宽网格、列内容居中、左右留白，斑马纹与悬停高亮
- **`/api/status` 新增 `recentLogins` 字段** — 供监控页及脚本采集最近登录流水

---

## 🐛 Bug 修复

- **趋势曲线过冲** — 修复平滑曲线（Catmull-Rom）在「零值段紧邻峰值段」时切线过冲、越过 0 基线向下弯曲的显示问题；现对贝塞尔控制点纵坐标按线段两端点值钳制，两零点间恒为水平直线
- **服务信息被挤出可视区** — 监控页布局调整后右栏「服务信息」卡片不再被拉伸裁切，8 个显示项完整可见

## 🔄 API 变更

业务接口无变更。`GET /api/status` 响应新增：

| 字段 | 说明 |
| --- | --- |
| `recentLogins[]` | 最近登录流水：`time`（含年份）/ `app` / `userid` / `name`（未开启 `fetch_name` 时为空）/ `remote`（登录发起 IP） |
| `cards.ticketsToday` | 今日 ticket 签发数 |
| `series[].rejects` | 逐日拒绝事件合计 |

`state` 存储记录新增 `remote` 字段（仅内部使用，存储 JSON 向下兼容）。

## 🔄 升级说明

1. 配置无需迁移：新增能力随 `status.enabled` 开关生效，存量配置零影响
2. 姓名列依赖 `wecom.fetch_name: true`（需应用具备通讯录读取权限）；未开启时流水姓名显示 `-`
3. 最近登录含用户账号与 IP 信息，请妥善保管 `status.token`，必要时在 Nginx 对 `/status`、`/api/status` 追加来源限制
4. 升级后执行 `./wecom-auth-center -v` 确认版本已更新
